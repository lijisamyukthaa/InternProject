# Headbrain Data Analysis

This repository contains a Jupyter Notebook analyzing the relationship between head size and brain weight using the `headbrain.csv` dataset.

## 📁 Files Included

- `headbrain_Df (1).ipynb` - Main Jupyter notebook with code and visualizations
- `headbrain.csv` - Dataset containing head size and brain weight data

## 📊 Visualizations Used

The notebook includes the following charts:
- Histogram
- Scatter Plot
- Box Plot


## 🛠️ Tools & Libraries

- Python
- Pandas
- Matplotlib
- Seaborn (optional for pairplots)
